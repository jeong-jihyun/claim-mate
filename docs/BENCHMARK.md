# 벤치마킹 정리 (2026-10-29 조사)

## 조사한 서비스와 우리 앱이 가져온 점

| 서비스 | 핵심 흐름·기능 | 청구메이트 반영 |
|---|---|---|
| 실손24 (보험개발원) | 본인인증 → 보험계약 선택 → 병원 선택 → 진료일·내역 선택 → 청구서 작성 → 확인·전송 → 완료. 자녀 청구·제3자(부모) 청구. 신규/추가 청구. 비연계 병원은 사진·PDF 별도 첨부 | 청구 만들기 마법사(누구/유형/병원/날짜/보험사), 본인·자녀·부모 구분, 증빙 사진·PDF 첨부 |
| 토스·네이버 | 결제 알림 → 간편 청구 → 실손24 연결. 연계 병원만 가능 | 홈 상단 "먼저 실손24 연계 여부 확인" 안내, 청구 기한 알림 |
| 보닥·보험사 앱 | 카메라 촬영·파일 업로드로 서류 제출 | 서류별 촬영/앨범/파일 버튼 |
| 지앤넷 빠른청구 등 | 미연동 병원은 서류 데이터를 모아 전송 | 서류 묶음 PDF + 공유 |
| 실비실손보험 청구(한일통신) | 청구서류 준비 안내, 절차 안내, 고객센터 안내 | 상황별 체크리스트, "어디서 받나요?" 안내 |

## 우리 앱의 차별점
- 연계되지 않은 병원(2026-09-28 기준 연계율 47.7%)에서 서류를 직접 모으는 사람을 위한 체크리스트형 도구
- 서류를 한 개의 PDF로 묶어 보험사 앱/이메일/팩스 어디로든 전달
- 진료 서류를 서버에 올리지 않고 폰 안에만 저장 (민감정보 최소 수집)

## 이번에 일부러 넣지 않은 것
- 실손24 직접 연동: 보험개발원·중개기관 제휴가 필요해 보여 2단계 이후로 둠
- 병원 기록 대리 수령: 의료법 제21조에 따라 환자 본인 요청 또는 동의서+위임장이 필요해 앱이 임의로 가져올 수 없음
- 보험사별 접수 이메일·팩스 번호: 검증된 값이 없어 넣지 않음 (공유 시트에서 직접 선택)
