# 요건 → 앱 반영 표

| 요건 | 근거 | 앱에서 하는 일 | 코드 위치 |
|---|---|---|---|
| 공통 서류(신분증, 통장, 진료비 영수증, 세부내역서) | 보험사 구비서류 안내 | 모든 청구에 기본 체크리스트로 표시 | `src/data/documents.ts` `common()` |
| 통원: 진단서·통원확인서·처방전 등 중 1개 | 보험사 구비서류 | 같은 묶음 안에서 1개만 올리면 충족 | `proof('outpatient')`, `getProgress()` |
| 입원: 진단서 또는 입퇴원확인서 | 보험사 구비서류 | 입원 증빙 묶음 | `proof('inpatient')` |
| 수술: 수술확인서 또는 진단서 | 보험사 구비서류 | 수술 증빙 묶음 + 입퇴원확인서(선택) | `proof('surgery')` |
| 약국: 질병코드 처방전 + 약제비 영수증 | 보험사 구비서류 | 약국 전용 목록 | `common('pharmacy')` |
| 카드 영수증은 심사 불가 | 보험사·금감원 반려 사유 | 확인 항목으로 경고 | `notcard` |
| 청구권 소멸시효 3년 | 상법 | 기한 D-day 표시, 기한 30일 전 알림, 지난 건 생성 시 경고 | `daysLeft()`, `src/notify.ts` |
| 본인이 아닌 청구(자녀·부모) | 실손24 자녀/제3자 청구, 의료법 시행규칙 | 위임장·동의서(부모), 가족관계증명서(자녀, 선택) 항목 추가 | `proxyItems()` |
| 진료기록 사본은 본인 요청 또는 동의서+위임장 | 의료법 제21조 | 앱은 기록을 대신 가져오지 않고 "어디서 받나요?" 안내만 제공 | 각 항목 `request` |
| 진료정보는 민감정보 | 개인정보보호법 | 서버 전송 없이 기기 내부 저장 | `src/storage.ts` |
| 정식 청구서·개인(신용)정보 동의서 | 보험사 필수 동의서 | 확인 항목 + 요약표를 PDF 첫 장에 삽입 (정식 양식은 보험사 것을 사용) | `src/pdf.ts` |

## 새 서류 요건이 생기면
1. `src/data/documents.ts`에서 해당 유형 함수(`common`, `proof`, `proxyItems`)에 `DocItem`을 추가
2. 둘 중 하나만 있으면 되는 서류는 같은 `group` 값을 준다
3. `npx tsc --noEmit`로 확인
