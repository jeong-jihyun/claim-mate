# 청구메이트 (ClaimMate)

병원 서류를 모아 보험사에 보낼 **PDF 한 개**로 만들어 주는 실손보험 청구 도우미 앱 (Expo / React Native, SDK 58).

## 기능
- 청구 만들기: 누구(본인/자녀/부모) · 유형(통원/입원/수술/약국) · 병원 · 진료일 · 금액 · 보험사
- 상황별 서류 체크리스트, 둘 중 하나만 있으면 되는 서류 묶음 처리
- 서류 촬영 / 앨범 / 파일(PDF) 첨부, "어디서 받나요?" 안내
- 청구 요약표 + 이미지 서류 + PDF 서류를 한 개의 PDF로 합치기
- 공유 시트로 보험사 앱·이메일·팩스 앱에 전달, 전달 완료 표시
- 청구 기한(진료일+3년) D-day와 30일 전 알림
- 서류는 기기 안에만 저장 (서버 전송 없음)

## 실행
```bash
npm install
npx expo start          # 폰의 Expo Go로 QR 스캔
npx tsc --noEmit        # 타입 검사
```
Expo Go에서 알림은 일부 제한이 있을 수 있어요. 정식 알림 테스트는 개발 빌드(`npx expo run:android`)에서 하세요.

## 폴더
- `src/data/documents.ts` 서류 요건 규칙 (여기만 고치면 목록이 바뀜)
- `src/pdf.ts` PDF 묶음 만들기
- `src/storage.ts` 기기 내부 저장
- `docs/BENCHMARK.md` 벤치마킹 정리, `docs/REQUIREMENTS.md` 요건 반영 표

## 한계와 다음 단계

2. 위임장·동의서 전자서명 자동 작성 (의료법 시행규칙 서식 기반)
